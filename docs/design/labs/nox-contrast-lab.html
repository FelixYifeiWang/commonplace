Nox on dark desktops

Nox's window can't see the desktop behind it, so the bubble has to bring its own contrast. Four ways to keep the black N readable, each on the same four wallpapers. Under each tile is the mark's contrast with what is directly behind it; 3:1 is the usual floor for a graphic.

The N is drawn with WebGL, which this browser has turned off.

Reading it

Milky glass ships for now. It reads at rest and while working on every wallpaper; Paused and Error are its weak spots on dark desktops.

Soft glow was the recommendation. With the N now black, the glass has to do all the work on dark desktops, where today's nearly clear bubble gives 1.1:1. Soft glow and Light rim are the only options that hold in every state on every wallpaper, because they put light right against the mark instead of a grey pool under it. Soft glow does it without drawing a line: on light desktops it disappears and the N looks exactly like the logo, and on dark ones the N looks backlit. The glass stays clear and the N's shape and motion are untouched.

Light rim is the crisper version of the same idea, a die-cut outline around the N. Lit core is one CSS background and reads well at rest, but its pool of light is a mid grey over dark desktops, so the grey Paused N and the orange Error N lose contrast there. Milky glass has the same problem and turns Nox into a white button. Switch the state to Paused or Error to compare.
